# خطوات نحو التميز

موقع تعليمي عربي يعمل على Vercel، بواجهة صفحات HTML وواجهة API صغيرة، ويستخدم Firebase Authentication لتسجيل الدخول وFirestore لحفظ بيانات الكورسات والطلاب.

## خريطة الملفات

```text
README.md                   هذا الدليل
.gitignore                  يستبعد الأسرار والملفات المؤقتة من Git
index.html                  الصفحة العامة وصفحة الطلاب
script.js                   منطق الصفحة العامة والطلاب وقراءة بيانات Firebase
style.css                   تصميم وألوان وتنسيق الصفحات
admin.html                  لوحة إدارة الكورسات والدروس والطلاب
api/upload-image.js         واجهة Vercel الآمنة لرفع الصور أو تحويل رابط المشاركة لرابط مباشر
api/image.js                وسيط الصور: يجيب صورة الكورس/الدرس من نفس الدومين بدل موقع الاستضافة
lib/image-host.js           أدوات الصور المشتركة بين الموقع وواجهة الرفع
firestore.rules             صلاحيات القراءة والكتابة والتحقق من بيانات Firestore
vercel.json                 إعدادات Vercel وترويسات الحماية وسياسة مصادر الصور
_env.example                مثال لمتغيرات البيئة المطلوبة؛ لا يُحمّل تلقائيًا
logo-steps-excellence.png   شعار الموقع المستخدم في الصفحة
logo-steps-excellence.svg   نسخة SVG بديلة من الشعار
tests/image-host.test.js    اختبارات رفع الصور ووسيط الصور والتحقق من الروابط
```

### وظيفة كل جزء

- **`index.html`**: هيكل الصفحة الذي يراه الزائر والطالب: الأقسام، النوافذ، الأزرار، والنماذج. لو المطلوب تغيير نص أو إضافة قسم مرئي، ابدأ من هنا.
- **`script.js`**: السلوك البرمجي للصفحة العامة والطلاب؛ يتصل بـ Firebase، يحمّل الكورسات والدروس، ويتعامل مع تسجيل الدخول والتقدم والصور.
- **`style.css`**: شكل الموقع فقط؛ الألوان، الخطوط، الهواتف، البطاقات، الحركات والمسافات. تعديله لا يغيّر بيانات Firebase.
- **`admin.html`**: صفحة لوحة الإدارة. فيها نماذج إضافة وتعديل الكورسات والدروس وإدارة الطلاب، واتصال Firebase الخاص بالإدارة.
- **`api/upload-image.js`**: مسار السيرفر `/api/upload-image`. يتحقق من Firebase ID token وصلاحية الأدمن قبل رفع الملف أو حل رابط مشاركة.
- **`api/image.js`**: مسار السيرفر `/api/image?u=...`. يمرّر صورة الكورس أو الدرس من نفس دومين الموقع بعد التحقق من المضيف الموثوق ومن بايتات الصورة نفسها. لا يحتاج أي متغيرات بيئة جديدة.
- **`lib/image-host.js`**: قواعد روابط الصور الموثوقة، وتحويل روابط Postimages/ImgBB إلى روابط صور مباشرة، وبناء رابط `/api/image`. تستخدمه واجهة الموقع والأدمن للتحقق بالطريقة نفسها، كما يستعمله مسار الرفع ووسيط الصور على السيرفر.
- **`firestore.rules`**: الحارس الذي يقرر من يقرأ أو يكتب كل مجموعة في Firebase. تغيير هذه القواعد يؤثر على صلاحيات الطلاب والأدمن.
- **`vercel.json`**: إعدادات النشر على Vercel، خصوصًا ترويسات الحماية ومصادر الصور المسموح بها.
- **`_env.example`**: أسماء متغيرات البيئة المطلوبة كمثال. القيم الحقيقية تُضبط في إعدادات Vercel، ولا تضع مفاتيح سرية في JavaScript أو Git.
- **`tests/image-host.test.js`**: اختبارات محلية للتأكد من صحة رفع/حل روابط الصور، ووسيط الصور `/api/image`، ورفض الروابط غير الموثوقة.
- **ملفا الشعار**: `logo-steps-excellence.png` مستخدم في الصفحة، و`logo-steps-excellence.svg` نسخة بديلة.

## مسار حفظ صورة الكورس أو الدرس

1. الأدمن يختار صورة أو يضع رابطًا من Postimages/ImgBB.
2. المتصفح يرسل الصورة إلى `/api/upload-image` مع Firebase ID token.
3. السيرفر يتحقق أن المستخدم أدمن نشط، ثم يرفع الصورة إلى Postimages ويستخرج رابط الصورة المباشر.
4. لوحة الإدارة تحفظ الرابط في حقل `imageUrl` داخل مستند الكورس أو الدرس في Firestore.
5. صفحة الطالب تقرأ `imageUrl` وتعرض الصورة إذا كان الرابط من مصدر موثوق.

## مسار عرض الصورة في الصفحات (ولماذا عبر `/api/image`)

1. الصفحة تحوّل `imageUrl` إلى رابط من نفس الدومين: `/api/image?u=<الرابط>`.
2. السيرفر يتحقق أن المضيف من المصادر الموثوقة، ثم يجيب الصورة ويتأكد من بايتاتها الفعلية (JPEG/PNG/GIF/WebP/BMP) قبل إرسالها بترويسة `Cache-Control` طويلة.
3. لو ردّ المضيف بصفحة HTML بدل الصورة (رابط صفحة أو حماية هوت-لينك)، يقرأ السيرفر وسم `og:image` من الصفحة ويجيب رابط الصورة المباشر.
4. لو فشل السيرفر، يجرب المتصفح الرابط المباشر من موقع الصور.
5. لو فشل الاثنان، تُعرض أيقونة الكورس/الدرس الافتراضية بدل علامة الصورة المكسورة.

السبب: مصادر مثل Postimages قد تُحجب على شبكة الزائر أو يعاملها مانع الإعلانات كإعلان، وروابط صفحاتها (`postimg.cc/xxxx`) ليست صورًا مباشرة، لذلك لا تُستخدم أبدًا داخل `<img src>`.

لو سجل قديم فيه رابط صفحة مشاركة بدل رابط الصورة المباشر، افتح العنصر من لوحة الإدارة واحفظه مرة أخرى؛ محاولة الحفظ تحوّل رابط المشاركة إلى الرابط المباشر.

## إعداد رفع الصور على Vercel

اضبط المتغيرات التالية في Vercel ثم أعد النشر:

- `FIREBASE_PROJECT_ID`
- `ALLOWED_ORIGINS` — أصول الموقع المسموح بها، مفصولة بفواصل عند الحاجة، مثل `https://khutuwat.vercel.app`
- `POSTIMAGES_API_KEY`
- `POSTIMAGES_GALLERY` اختياري

ملف `_env.example` للتوضيح فقط ولا يحمّله Vercel تلقائيًا. يمكن الحصول على مفتاح Postimages من https://postimages.org/login/api. لا تضع المفتاح في `admin.html` أو `script.js` ولا ترفعه إلى Git.

يعتمد التكامل على صيغة Postimages المتوافقة مع تطبيق سطح المكتب؛ الاختبارات تستخدم ردودًا وهمية ولا تثبت أن خدمة Postimages متاحة لحسابك حاليًا.

## تشغيل الاختبارات

```bash
node --test tests/image-host.test.js
```

الاختبارات تتحقق من سلوك الكود محليًا، لكنها لا تنفذ رفعًا حقيقيًا إلى Postimages أو Firebase.
